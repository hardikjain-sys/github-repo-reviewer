# AI Github Repository Reviewer

This analyzes GitHub repositories for architecture, dependencies, documentation, testing, and overall code quality using AI.

**Architecture Reviewer:** Assesses how well the codebase is organized, how responsibilities are split, and whether the project structure feels scalable.
<br><br>
**Documentation Reviewer:** Checks whether the repository explains itself clearly through README files, setup steps, usage examples, and contributor guidance.<br><br>

**Testing Reviewer:** Evaluates whether the project has enough tests, whether core behavior is covered, and whether the testing strategy looks reliable.<br><br>

**Code Quality Reviewer:** Judges readability, consistency, modularity, naming, and whether the codebase looks maintainable.<br><br>

**Dependency Reviewer:** Reviews the project’s external libraries and setup files to identify dependency bloat, outdated choices, or unnecessary complexity.<br><br>

**Aggregator/Final Judge:** Combines the specialist findings into one coherent review with scores, priorities, and actionable suggestions.<br><br>

**Working link - https://github-repo-reviewer.vercel.app/**<br> (It may take a few seconds for the first review because of free version of Render where backend is there which takes time to come back live from sleep)
